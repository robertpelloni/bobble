# OmniCore Ideas

For each repo, think creatively to generate aggressive ideas for pivots, refactoring, re-architecting, language porting, or feature expansions. Go nuts.

- Implement LLM-based intelligent auto-reply system with local models (llama.cpp or Ollama).
- Build custom hardware appliance for standalone 24/7 routing (Raspberry Pi CM4 compute module with cellular modem hat).
- Automated P2P Mesh Routing fallback when WAN is severed (using Libp2p or Tox DHT).
- Zero-Knowledge multi-device key ratchet synchronization via encrypted Matrix state events.
- Audio / Video call aggregation bridging WebRTC, Discord Voice, Matrix VoIP, and Signal calling.
- Port the consolidated dashboard layout to the mobile shell (People/Conversation/Bridges stack with the same routing-profile picker).
- Make routing profiles executable presets: map each dashboard profile to a concrete MultipathRouter strategy chain and show per-message which strategy delivered it.
- Tray v2: dynamic tray title showing connected-bridge count and paused state; per-bridge submenu toggles.
- One-click diagnostics bundle: export Activity log + capability map + telemetry as a shareable support report.
