# bobble

**Design/spec repository** for a universal messaging client — a next-generation Trillian/Pidgin-style aggregator (working design name "OmniCore") that brings every messaging platform into one fully-featured desktop + mobile app: Signal, Simplex, Molly, LINE, Matrix, Tox, Discord, iMessage, RCS, Android messaging, and SMS — with no platform treated as second-class, including routing a conversation across multiple platforms when that's what reaching the person takes.

## Current state of this repo

This repo contains **only the design document** — the architecture and strategy specification (previously the entire README, written as a build brief for Google Jules to implement on autopilot), including why the design moves away from the legacy libpurple/Trillian architecture. There is no code here yet.

## Status

Spec stage. One of Robert Pelloni's bob* ecosystem projects (bob's game, bobzilla, bobcoin, …) — currently a blueprint, not a build.
